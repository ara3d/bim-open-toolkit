One query reads each door and window with its storey and its IFC OverallWidth and OverallHeight (metres in the model, shown in millimetres); Area_m2 is width times height, summed per schedule line. A line is one storey, kind, type and size, so a type with two sizes shows as two lines; an opening with no size keeps an empty size and area, never zero. The bars are one per line, their length the count, coloured by opening type; the spec groups them by storey. The 3D view colours openings with the same type colours and fades everything else to 15 percent. Check sizes against the type name before pricing: the README lists a skylight whose IFC height disagrees with its type.");
