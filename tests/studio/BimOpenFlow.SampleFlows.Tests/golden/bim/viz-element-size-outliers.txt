Read the figure: the scatter (specs/viz-element-size-outliers.vl.json) plots Volume on a log scale against Height, one colour per class, outliers drawn large and outlined; the bar chart ranks every element by Fold on the same colour scale as the 3D view, which ghosts everything except the outliers.
