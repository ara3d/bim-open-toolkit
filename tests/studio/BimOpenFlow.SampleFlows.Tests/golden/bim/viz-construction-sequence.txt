Role: a site superintendent. Question: in what order do the Duplex's floors and trades get built, and which parts are finished by which week? The dates are synthetic: bim.buildSequence invents a floor-by-floor cycle from the model and reads no real programme.
How it schedules: storeys run bottom-up; trades run Structure, Envelope, MEP, Finishes, each task 10 calendar days from Monday 2027-01-04. A trade starts a storey once the trade before it has left that storey and its own crew has left the storey below, so trades overlap by one floor. A trade with no elements in the model (the Duplex has no MEP) takes no time; IfcSpace rows belong to no trade and stay unscheduled (one warning on 'sequence'). Storeys come from StoreyOfElement in the DuckDB export ('elements'), because bim.elements has no Level for an IFC-derived model.
How to read it: 'taskChart' has one bar of elements per task, coloured by finish week; 'taskTable' lists each task's dates; the Gantt in specs/viz-construction-sequence.vl.json draws a bar from Start to End per task, coloured by trade. The 3D view ('colored') colours each element by the week its task finishes on the same viridis scale ('weeks'): dark is early, yellow late; grey parts have no storey or no trade.
The schedule for the Duplex is in samples/viz-analyses/README.md.
""");
