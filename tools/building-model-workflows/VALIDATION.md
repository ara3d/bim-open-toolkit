# Core workflow validation

The runner validates the source-backed core architectural slice: storeys, spaces, doors, roofs, coverage, diagnostics, persisted reopening and source-local portfolio coverage.

The retained sample artifacts show that door schedules are already useful for selected Revit exports, while room-area and roof-quantity mappings still need field-specific source interpretation. Those gaps are reported as unresolved values rather than fabricated defaults.

This validation does not claim pricing, procurement, maintenance, carbon, egress, acoustic or compliance capabilities. Those records and calculations are outside the core model.
