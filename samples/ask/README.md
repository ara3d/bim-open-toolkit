# Ask request sets

Request files for `scripts/ask-bim-flow.mjs --file` and the transcripts of their runs; each file's header says how its expected answers were computed.

The expected answers in `requests.txt` and `toolkit-requests.txt`, and the replies in `toolkit-transcript-2026-09-29.txt`, were computed over the Snowdon DuckDB export: Autodesk's Snowdon Towers Sample Project, CC BY-NC-SA 3.0. See `samples/snowdon-analyses/NOTICE.md` for the attribution and what that means for a commercial fork.
