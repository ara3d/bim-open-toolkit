# Independent review of visualization V2, 2026-09-08

Question asked: are we making real progress, or running in circles?

Answer: real progress, with waste. The contracts that landed are usable — I used them — but a fifth
of the output is documents about the work, one track wrote 1,255 lines of fixtures against a data
shape the contract does not have, and nothing a user can look at has changed.

## Does the contract compose?

Yes. I wrote a throwaway script outside the repository importing both packages from source and did
the F26/F23 door review. Output in the appendix.

Worked in a few lines each, as documented: `generateBuilding(defaultBuildingOptions)`; fire-rating
coverage via `completeFacts` and `coverageOfFacts` (29 doors, 11 known, 16 missing, 2 conflicting);
reconciling a conflict (`EI90` vs `EI60` stayed `conflicting` when a survey added `FD60`, and became
`known` from the survey alone); a style rule returning `[1,0,0]` for the 16 unrated doors and grey
elsewhere. Nothing was invented for a gap.

Workarounds: putting instance records into a `Table` is a hand-written per-row loop calling
`instanceTransform`, which allocates a 16-number array per row — at 456,598 instances that is exactly
the allocation the rewrite exists to remove, and both structures sit in the same package with no
bridge. Reading a cell needs the column narrowed by hand each time.

Impossible: joining the door schedule to the instance table (`joinTables` needs integer keys, the
schedule keys on a string); filtering a table by an `ObjectSet`; and anything visual — no scene,
viewer, command dispatch or saved document. `Session` is a type with a test fixture and no
implementation.

A contract that cannot be used is ceremony. This one can be used, which is the strongest evidence the
work is real.

## Rewrite risk

The alpha (1,849 source + 1,622 test + 1,875 example lines, 22 demos, 290 tests, Snowdon rendering in
a browser) has something implemented and tested on every F01–F27 row except the postponed three. V2
replaces none of them yet, but nothing is being rebuilt without a reason. Premise 3 of "Why a new
plan" is now measured: `viewer/packages/testing/docs/normalized-bindings.md` reports the columnar
table is *"about five times faster and twenty-four times smaller"*, parity-checked against the
shipped loader. Premises 1, 2 and 4 — default composition, feature slices, workflow demos — are still
entirely promised: `viewer`, `features` and `workflows` hold one skeleton file each.

## Circles

Real, and small so far.

- **Two hours lost.** `751e62a` "seven concurrent subagents stalled the host; limit set to three",
  reversed 20 minutes later by `1c1ccbb` "stall was a disconnection; seven tracks running again";
  commits stop at 20:05 and resume at 22:15. Tracks were relaunched from their checkpoints, the one
  process artifact that clearly paid for itself.
- **W0's fixtures describe a shape that does not exist.** Its checkpoint calls the observations *"a
  flattened stand-in for the real (more deeply nested, with evidence lists) `Observation` type"*,
  leaves eight open questions for Track W, and invents its own inputs instead of using `synthetic`,
  so they get reconciled twice.
- **The ledger works.** Type-aware lint was measured (8 runs, caught nothing) and scoped down the
  same day — the right kind of reversal.
- **Status churn.** `V2-STATUS.md` has 11 commits and `V2-PLAN.md` 7 in about a day.
- No fixture or test I read checks the implementation rather than a requirement.

## User-visible outcome

Nothing yet. `npm run demo` still starts the alpha gallery; every V2 package that would put pixels on
a screen (`render`, `formats`, `features`, `viewer`, `ui-gratify`, `ui-react`) holds one skeleton
file, and the only runnable V2 artifact is a fixture file server with nothing to consume it. Wave 1's
acceptance names a "formats gallery", but the track owning the gallery host (D) is in wave 2, so the
first visible thing is two waves away. The landed work is on the path to it: `model` and `interact`
feed the viewer and both measurement studies feed `render`. W0's fixtures are the piece beside it.

## Verdict

**Real progress with waste.** The waste, named: 156k tokens on fixtures written against a guessed
data shape before the contract existed, and 1,736 lines of checkpoint and decision prose for one day
of work on two packages.

Three changes, highest value first:

1. Have Track W regenerate W0's ten cases from `synthetic` and `facts.ts`, and write no more fixtures
   ahead of the contract they describe.
2. Pull one end-to-end slice forward — synthetic building to `render` to a page that draws it and
   colours the unrated doors red — so premises 1, 2 and 4 get the measured treatment premise 3 got.
3. Add the two bridges the probe hit: instance columns to `Table`, and `ObjectSet` to table rows,
   because every recipe will otherwise hand-write them.
