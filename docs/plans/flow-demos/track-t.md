## T2

Investigation: BFAST buffers are raw bytes; the container records names and byte
ranges and no element types (`submodules/ara3d-sdk/src/Ara3D.IO.BFAST/spec.txt`).
The toolkit writes BFAST in `src/data/Ara3D.BimOpenSchema.IO.Bfast/BosBfastSerializer.cs`
(a BOS as nine named buffers) and `BuildingModel.Source/SourceCache.cs`; the 3D
pane receives prepared geometry as BFAST from the host (`viz/packages/formats/src/bfast.ts`,
`viz/packages/loaders/src/bfast-writer.ts`). No `.bfast` file was committed anywhere
and no node read one.

Design: `bfast.read` (path) lists `name`, `byteLength`, `index` from the directory
through the memory-mapped `BFastReader`, never touching buffer bytes. Because the
API exposes no typed buffers, `bfast.buffer` takes `path`, `name`, and a `type`
Enum (uint8, int16, int32, int64, float32, float64; default float32) and returns
one `value` column, integers widened to long and floats to double, so downstream
DuckDB-backed nodes see the two types they already handle. Unknown names list the
buffers present; a length that is not a multiple of the element size names the
buffer and its size. Both cache by content hash (`FileHashes`), as `xlsx.sheets` does.

  `src/flow/BimOpenFlow.NodeDocs/NodeNotes.cs` (outside this fence); the Spec
  descriptions carry the behaviour for now.
- **Finding (SDK, out of fence)**: `BFast.Read(string)` / `ReadBFast(Stream)` in
  `submodules/ara3d-sdk/src/Ara3D.IO.BFAST/BFast.cs` seeks to `DataStart + range.Begin`,
  but the ranges the same library writes are absolute, so the stream reader throws
  `EndOfStreamException` on files the SDK writer produced. The memory-mapped
  `BFastReader` reads them correctly; the nodes and tests use only that path.
- **Finding (SDK)**: `BFast.Write(string filePath, ...)` opens with `File.OpenWrite`
  and does not truncate; `SampleBfast.Write` deletes first.
- **Deferred**: the `{SAMPLES}/../tables` path is a workaround for a single showcase
  placeholder. A second placeholder (`{TABLES}`) in `SampleSeeding.ShowcaseAnalyses`
  would remove it; that is Host code outside this fence.
- **Deferred**: per-element-type column naming (`value`) is fixed; a `column` param
  can follow if a graph needs two buffers joined by position.
