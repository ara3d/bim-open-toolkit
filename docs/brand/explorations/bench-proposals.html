BIM Open Bench: brand proposals

2026-10-11. BIM Open Bench (ara3d/bim-open-bench) measures tools that read building models: parsers, meshers, viewers, and AI agents, on public IFC models with known answers. It joins the five products in docs/BRANDING.md and takes everything from the family except a mark and an accent.

Recommendation: B1 Ranked Rows in ochre

  • Accent: ochre #8f6214, soft #f5ecdc. The only hue left between rose and the Flow blue that no product or status colour uses. It was the runner-up for the schema on 2026-10-03, so it already sits in the family palette. Contrast on white is 5.35:1, the same as the Flow blue, so it works for link text. It reads as brass, a measuring instrument, not as the amber pending status (#d97706), which is brighter and more orange.
  • Mark: Ranked Rows. The family's three rows, set against a start line at different lengths, the longest ending in the node disc: tools ranked on one measure, the best reaching the answer. It is the only family mark whose rows differ in length, which is what a result looks like.
  • The rows grow downward, so the start line and rows read as steps rather than the letter F, which the first draft (longest row on top) did at 16 px.
  • Weakness: away from the family it can pass for a generic bar chart. The node disc and the ochre are what tie it back.
