## Reading the inventory safely

“Implemented” here means substantive source is present and its purpose was inspected; per-package verification claims come from the linked documentation unless the report explicitly says they were rerun. “Latest” can be a README/checkpoint edit. A clean typecheck can include an empty public export. A sample can exist without its private input. Check all four before calling something ready for another developer.
