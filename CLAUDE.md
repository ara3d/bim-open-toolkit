Install the platonic-coder plugin from the platonic marketplace (github.com/cdiggins/platonic-coder):

```
claude plugin marketplace add cdiggins/platonic-coder
claude plugin install platonic-coder@platonic
```

If the marketplace is unavailable, send an email request to [info@ara3d.com](mailto:info@ara3d.com?subject=platonic%20coder%20skill%20request)
