# tickets

Work items and open design questions for this repository, one `TKT-<n>.md` file each, managed with platonic-coder's `ticket.py`: `python ~/.claude/plugins/marketplaces/platonic/scripts/ticket.py --dir tickets <command>` (its `scripts/README.md` describes the format and commands). A ticket with `kind: question` is a decision someone must make: write the decision and its reason in the body, then close it. A task ticket names the `PROJECT.md` workflow it serves in its body, so the work can be checked against that workflow's Done line.
