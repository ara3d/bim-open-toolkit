# tickets

Work items and open design questions for this repository, one `TKT-<n>.md` file each, managed with platonic-coder's `ticket.py`: `python ~/.claude/plugins/marketplaces/platonic/scripts/ticket.py --dir tickets <command>` (its `scripts/README.md` describes the format and commands). A ticket with `kind: question` is a decision someone must make: write the decision and its reason in the body, then close it. Every ticket names the `PROJECT.md` workflow it serves in its `workflow:` field (`[W2]`, or `[W2, W3]` for two), so the work can be checked against that workflow's Done line and the dashboard's Brief panel can count open and done tickets per workflow; `ticket.py new --workflow 2` writes it and `ticket.py list --workflow W2` filters on it. Two words mark the work that serves no workflow: `kept` for a Scope In line the brief keeps but no longer drives priorities by (the rule check and its evidence package, the NRC paper reproduction and byte-exact write-back), and `process` for the repository's own tooling, tests, and debt. Tickets filed before 2026-10-05 also say "Serves W<n>" in their body; the old numbering those lines use is mapped in `docs/plans/brief-alignment-2026-10-04.md`, and the field, not the prose, is the record.
