## Findings
- Results are bit-identical: every `*Given` measure is its library measure's expression with the guard passed in, and every `Law_Perf_*` compares the Check field for field (`Identical`: law, holds, worst, bound, where), including on failing inputs (the cylinder against the box's mesh fails all three cross checks; the runner's models and plans fail some topology checks).
- The plan and ticket name the agreement laws `BrepValidationLaws.Law_*CheckAgrees`; they live in `BrepCheckingLaws` (07 validation.laws.plato).
- `CanCompareElementGiven` takes ok = IsEveryIndexInRange && Geometry.IsWellFormed (`IsIndexedAndWellFormed`) and tests the element's face after it; the library form tests IsWellFormed after the face. Same Boolean, both operands pure. One difference in work, not value: the hoisted check evaluates Geometry.IsWellFormed once even on a mesh with no elements.
- Under the C# backend, `WitnessMesh` takes 3.9 s on the unit box, 13 s on the block with a hole and over 20 s (abandoned) on the cylinder, run as three laws at once; the interpreter meshed all four of this chunk's first witnesses in about 24 s. A witness has no budget, so a `Witness_*` that meshes the cylinder hung the compiled run (killed after 10 min, twice). This chunk keeps only unit-box meshes. Chunk L1's `MeshedWitness` will meet the same cost: worth measuring compiled meshing per witness before L1 lists its witnesses.
- On the warm server the first run after a recompile gave `Law_Perf_WitnessCrossChecksHoistedAgree` 1 case of 4; a second run, with the witnesses cached, gave 4. Some witnesses were evidently dropped on the first build; the runner swallows a witness fault (LawRunner.EvaluateWitnesses) and the server does not print the witness list, so a law can pass on fewer cases than its witnesses. Worth a line in the server's output: witnesses built and witnesses faulted per type.

## Lessons
- A witness that meshes runs with no budget under the C# backend: run each candidate witness's build as a temporary law with `--abandon=20` first, so a slow one is named instead of hanging the run.
- Pass `--abandon` and a shell `timeout` to every compiled run; the default abandon is 120 s per law and witnesses have none.
