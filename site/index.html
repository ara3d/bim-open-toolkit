BIM OpenToolkit
Try it Repositories Run it GitHub

Get schedules, checks, charts, and 3D views out of a building model, without a vendor's API.

BIM Open Toolkit stores a model as plain tables (BIM Open Schema, or BOS) and turns each question about those tables into a small graph you can inspect and run again. A person and an AI agent build the graph with the same four edits, so an agent's answer arrives with the steps that produced it.

The repositories

The toolkit is being split into one repository per product. A product marked moving has its repository and README, but its code is still inside the toolkit at the path given.

BIM OpenViewer

ara3d/bim-open-viewer

Draws building models in the browser with three.js: hundreds of thousands of instances, per-object colour, sections, exploded layouts, and picking. Reads BOS, BFAST, GLB, GLTF, OBJ, and STL.

BIM OpenNotebook

A session with an AI agent kept as a document. Every result keeps a snapshot, and one backed by a graph can be evaluated again to show whether it changed.

The graph system: node packs over tables, a headless host that evaluates graphs and records runs, the web editor, and an MCP server so an agent edits the graph a person sees.

How the pieces fit

A model enters as an IFC file, or as a BOS file exported from Revit. Each layer below builds on the ones under it; the bottom row is general libraries that know nothing about buildings.

  1. bim-open-toolkit The analyst application: studio, BIM node packs, samples, checks. uses every product below
  2. bim-open-notebook Keeps a session with an agent as a document of graphs, tables, and views. uses flow, viewer
  3. bim-open-flow Turns a question into a graph of small nodes; nothing writes a file until an explicit Run, which records every input by content hash. uses ara3d-dataflow, gratify
    bim-open-viewer Draws the model; a graph's output colours it. uses gratify
    bim-open-data Reads IFC and BOS, converts to BOS, loads DuckDB, writes property sets back. uses bim-open-schema, ara3d-sdk
  4. ara3d-dataflowspecified graph engine
    gratifycanvas UI library
    bim-open-schemathe BOS specification
    ara3d-sdk.NET utilities

Each repository lists what it needs in deps.json and reads it only from its own deps/ folder. node deps.mjs fills that folder with a link to a sibling checkout or a clone at the pinned commit, so one checkout never holds two copies of a repository.

Run it yourself

Needs Windows, the .NET 8 SDK, Node.js 20.19 or 22.12 and later, and Git. This path ends at a table graph in the editor over committed sample tables; no private model is needed.

  1. Clone and fetch the dependencies 
    git clone --recursive https://github.com/ara3d/bim-open-toolkit
cd bim-open-toolkit
node deps.mjs
  2. Check prerequisites and install the editor 
    node scripts/preflight.mjs
npm ci --prefix bimopenflow/web
  3. Build and start the host and the editor 
    node scripts/start-bim-flow.mjs --profile tables

    Builds the host, starts it on port 5224 and the editor on 5310, and waits until both answer. Open http://127.0.0.1:5310/ and choose a sample analysis. --stop ends both.

The 3D, DuckDB, and Ask demos over the Snowdon Towers model need a private copy of that model; docs/START.md and docs/DEMOS.md list every demo and what it needs.
